# v0.2.5 验收记录

日期：2026-10-31。状态：代码及离线/界面验证完成，真实模型验收受额度限制，尚未发布。

## 已执行

- `npm run build:client`、`npm run build:contracts` 成功。
- `npm run check`：89 项测试通过，包括预算、续跑、引用、归档、人工注释冲突、安全 URL、输入检查、前后端模式一致性、进度分母及导出身份。
- `npm run test:host`：实际 Harness/Cordis 运行时加载和卸载，28 个工具注册，模拟适配器 6 次调用生成十模块报告并归档；只读权限与非法输入拒绝通过。此项不是付费模型验证。
- 实际本地 Web Harness 浏览器：原生“论文研究”入口、四视图切换、预设/自定义选择、运行期间保持任务并锁定会话切换、历史报告、Mermaid 图、证据抽屉及人工意见保存和回读。
- 模拟报告明确标注“模拟验收数据”，实际覆盖 1/3；人工复核保持“有疑问”并单独保存，原始结论分类不变。Escape 关闭后焦点回到“查看原文与复核”。
- 临时测试构建仅增加容器宽度选择器，在同一个实际 Harness 页面测量 1280、1050、800、390 四档。创建页和报告页 scrollWidth 均不大于 clientWidth；窄屏单列、目录分组，图表可见。测试构建随后用正式构建覆盖，不进入发布包。

- 最终界面真实公开来源检索返回 10 篇论文，包含 ReAct；“研究这篇”仅跳转并预填 arxiv:2210.03629v3，开始按钮待确认，没有启动模型。
- npm 安装包已生成且不含 acceptance-local 私有材料；在独立临时目录安装后运行全部 89 项测试通过。

## 实际限制与待完成

使用公开论文 ReAct（arxiv:2210.03629）从新界面开始研究，论文资料已取得；宿主 DeepSeek-V4.1-Flash High 在模型调用阶段返回 QUOTA / HTTP 402。错误显示并保存到历史，可继续完成研究。未声称真实模型生成通过。

需恢复模型额度或切换到用户指定的可用已配置模型，完成真实报告生成和归档后，再执行 GitHub 推送、v0.2.5 Release、npm 同一安装包发布及公开安装校验。当前未发布。

当前宿主不具备可信的调用前 Token 硬限额接口，因此工作台仅开放模型调用次数预算；Token 用量按实际返回值记录，未知费用不估算。

本次不实现 P1 的跨报告搜索、批量导出和筛选持久化，也不增加 PDF 双栏阅读器、OCR 或调度平台。
