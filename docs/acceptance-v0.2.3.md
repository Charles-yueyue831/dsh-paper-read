## 交付

- 报告位于独立宽幅阅读区；按阅读意图分组导航，旧英文 details 字段映射为中文标题。
- 新报告先给核心思想、价值、边界、行动概览。细节和附录默认折叠，提供展开/收起、证据跳转自动展开、源码与完整 Markdown 下载。
- paper/sandbox/experience/decision 模块输出有证据的节点关系图或具体缺失原因；程序验证节点、边、引用和事实类型，再生成 Mermaid。机制图、产品提案图分别标注，图旁保留解释和证据链接。
- 图表默认适应页面，可放大。内部标点使用不可引入语法的可读字符，避免 Mermaid 编码显示问题。
- 原文、旧报告及工具参数不变。promptVersion 为 0.2.3，跨版本继续时重新生成章节、复用原文证据。旧报告只改变阅读展示，不自动调用模型或改写文件。
