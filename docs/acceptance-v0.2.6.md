# v0.2.6 验收记录

验收日期：2026-11-02。用户指定以既有前端 UI 规范为基础发布 v0.2.6。

## 本版执行

- 前端构建成功；94 项单元/集成测试全部通过。
- 安装的官方 Harness/Cordis 运行时：28 个工具注册及卸载、6 次模拟模型调用生成十模块报告并落盘通过。该测试不代表真实付费模型调用。
- 独立 Harness Web profile，端口 3091：四视图加载，预算字段与运行后端一致；“研究这篇”仅预填并打开创建页；产品模式对应六个指定模块。
- 真实 Agent Sandbox 论文搜索：刷新页面后重新打开工作台，接回同一运行任务，等待时间持续累计，最终返回 10 篇。Semantic Scholar 返回 HTTP 429 时显示来源级提示，保留其他来源结果。
- 非论文诊断字符串触发 INVALID_REFERENCE，界面准确显示“尚未生成可恢复的研究记录”，没有错误宣称已保存。
- API 集成测试覆盖 activeJobs 仅返回存活会话的运行任务摘要，不返回请求正文、控制器或结果；完成后移除活动摘要。客户端测试覆盖不跨已选工作区接管任务。
- 前后端参数回归验证 analyze、resume 及所有单模块工具接受并保留 maxCalls/maxTotalTokens，同时仍拒绝无效预算及未知字段。

## 规范覆盖与边界

既有四视图、模式预设、真实预算、覆盖面板、独立人工复核、产品机会导出、软删除历史和响应式样式沿用 v0.2.5；详细原始验收见 acceptance-v0.2.5.md。本版未重复声称所有旧版 UI 项都重新人工验收。

未再次调用付费模型生成完整报告。P1 快捷键增强、报告全文搜索、筛选长期记忆，以及完整 PDF 双栏阅读器未新增。任务恢复只在同一后端进程任务仍运行时有效；后端重启后需要从持久化研究历史恢复。
