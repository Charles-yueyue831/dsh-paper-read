## 更易读的图文研究报告

研究报告改为独立宽幅阅读区，用分组导航与中文标题组织内容。重点概览先给结论，详细解析和证据按需展开；引用链接自动定位原文，完整 Markdown 与源码保留。

技术理解、Agent 沙箱、体验与 PoC 模块现在按证据生成具体机制图或流程图，区分论文事实与待验证方案，附解释和引用。材料不足时说明不绘图的原因；图表支持放大和适应页面。

已有报告兼容新阅读布局。需要补充图示时，在研究历史选择“重新分析选中内容”，新结果单独保存。

### 安装

```bash
dsh plugin --profile web add dsh-paper-insight@0.2.3
```

完成当前任务后重启 Harness、刷新浏览器，在侧边栏打开“论文研究”。
