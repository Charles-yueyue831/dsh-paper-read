# 0.2.0 实施方案

沿用 dsh-paper-insight 包名、paper-insight 插件名及六个旧工具；paper-to-product 是工作台名称。宿主已核实为 DSH 0.2.1-alpha.2，Cordis ESM apply/inject、tools.register、llm.prepareCall、sandboxPolicy.resolve；Web 使用 webServer.register、agents.list/get、客户端 main/sidebar.panellist 槽位。所有注册随 Cordis 生命周期释放，不改 Harness 核心。

## 实现顺序

1. 将分析拆成获取、文献、逐块证据、分组章节、导出等检查点；保存每步耗时、模型用量和错误。续跑复制最近检查点到新的运行版本，旧版本保留。指定模块重跑只复用原始文档及证据。
2. 增加高级筛选、合法学术 URL 导入、本地索引检索、版本差异、多论文比较；关注主题持久化并按论文内容/版本指纹增量发现。周期执行由现有 schedule 工具或外部调用触发。
3. 分析模板增加三类读者说明、公式解释、第一性原理八段链、沙箱适用等级、产品能力/功能方案、体验旅程、PoC 与停止条件。研究时间线/引用图从已检索数据生成，模型推断的继承关系另行标记。
4. Web 客户端用原生侧边栏入口；选择已有活动会话继承其工作区与模型，通过同源且仅本机的宿主路由启动任务、轮询进度、取消、查询历史。没有活动会话时给出明确提示。网页内容仅以文本呈现。
5. 离线异常和恢复测试、真实 Cordis 测试、真实公开论文/模型端到端、原生侧边栏实测；全部通过后打包、推送、Release 和 npm。

## 数据与兼容

默认 .paper-insight/<key>/<runId>/ 保持兼容。新增 checkpoint.json、events.json、产品方案及 PoC 导出、timeline.json、relations.mmd。运行版本有 parentRunId；旧 schemaVersion=1 报告可读。自定义输出目录须在当前会话工作区内。持久化状态文件原子写入；不保存密钥；只读会话禁止写入。并发有界，单篇检查点串行。

## 交付边界

实时研究依赖外部数据源，失败必须列出来源缺口。IEEE/ACM 元数据通过学术索引/DOI 取得，不绕过付费墙。默认保留提取文本及来源链接，不归档没有明确保存授权的远程二进制原文。研究图中的引用关系不等于技术继承。订阅只保存研究配置，不擅自创建用户定时任务。长期向量数据库不是本次必要依赖。
