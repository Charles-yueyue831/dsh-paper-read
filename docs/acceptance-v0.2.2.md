# v0.2.2 研究历史与恢复验收

验收日期：2026-10-18。独立 Harness Web profile，端口 3091，未修改 Harness 核心。

## 修复与实现

- 截图中的 HarnessNet 标题以前被当作 ID 解析。现在标题通过配置的真实学术来源检索，只有唯一完全匹配才自动选择；其他结果以候选返回，由用户选择。
- 拒绝把旧错误消息作为论文输入；错误不再无条件宣称“已提取材料”，key/runId 保留结构化字段。
- 旧 Pending paper 优先使用已保存的输入标题；旧 document.json 可用于继续分析。材料缺失时提供重新填写入口。
- 历史提供新建研究、名称/备注/全文查询、状态筛选、分页、详情、编辑、删除与恢复。record.json 独立保存用户备注、显示名称和版本，不修改原始论文或报告。删除为标记，可恢复。
- 新按钮“继续完成分析”“重新分析选中内容”附有说明；尚未取得材料时使用“重新尝试分析”。失败状态和常见原因用中文说明，原始错误可在详情展开。
- 名称/备注编辑支持版本冲突检查；当前进程活跃任务不能修改。主机重启后留下的 running 记录可识别为中断并继续。多进程不能同时写同一归档目录。
