# 真实模型端到端验收

验收日期：2026-10-17（Asia/Shanghai）。本记录区分真实运行与合成测试，不把测试替身当成论文分析结果。

## 环境与入口

- 在用户已有的本地 DeepSeek Harness 源码实例 `0.2.1-alpha.2`（`d743267`）中集成 Cordis 插件。
- 插件已安装并选入现有 `web` profile；实际验收使用独立 `paper-acceptance` profile，基于官方 headless 模板启动。
- 使用用户已有的 Harness 模型路由，经 `ctx.llm.prepareCall` 调用真实模型，没有使用模拟响应或直接绕过 Harness 调用模型。
- 模型凭据由 Harness 管理。验收用路由配置、完整会话轨迹和报告保存在本地，不随源码发布。
- 本机现有 Web 组合的新建会话弹层发生 React 渲染错误，未完成网页交互验收。此记录证明官方命令行会话的真实端到端流程，不声称已修复既有 Web 界面故障。

## 输入与实际结果

验收输入为自然语言：检索 **ReAct: Synergizing Reasoning and Acting in Language Models**，选择匹配论文，按用户要求分析技术、Agent 沙箱、产品新功能、新产品、体验、第一性原理矛盾、研究现状和文献、迁移、零基础解释，并保存和检查本地报告。提示词没有给出检索工具名或论文 ID。

模型自行选择 `paper_insight_search`，检索后调用 `paper_insight_analyze`，目标为 `arxiv:2210.03629v3`。分析工具完成后，Agent 又读取本地报告与证据进行核验。

## 十项要求核对

| 用户要求 | 对应验收证据 |
|---|---|
| 1. 爬取主流学术网站 AI 论文 | 多源检索事件、arXiv 目标记录与开放全文 |
| 2. Harness 模型分析、本地保存 | 真实工具调用、模型调用记录、completed manifest 和 8 个文件 |
| 3. 与 Agent 沙箱的关系和应用 | sandbox：研究复现、工具接口、权限、观测、回滚、资源与最小实验 |
| 4. 新产品功能或能力 | features：可审计时间线、轨迹编辑与分支重放、混合路由等提案 |
| 5. 创造新产品 | products：可审计检索行动工作台、目标用户、MVP 与否证实验 |
| 6. 提升产品体验 | experience：证据呈现、认知负担、控制感、延迟、纠错与 A/B 指标 |
| 7. 第一性原理与主要/次要矛盾 | first-principles：目标与有限预算、证据获取、推理行动匹配和次级成本 |
| 8. 现状、参考文献、研究脉络 | landscape：前驱与后续分支、36 篇来源、检索截止日期和覆盖限制 |
| 9. 技术迁移 | transfer：不变量、目标域假设、动作接口、负迁移及最小实验 |
| 10. 零基础解释和产品例子 | beginner：日常类比、类比边界、输入输出例子、研究系统与产品设想区分 |

人工检查涵盖全部章节。程序核验章节完整性、引用编号存在性、原文匹配、文件非空和归档状态。检查不会自动证明所有事实蕴含关系或产品可行性；例如“用沙箱开展研究是否成立”包含分析者判断，应连同引用及验证建议阅读，不能只依据类型标签认定为论文结论。

## 修复后再验收

真实测试发现并修复了三个问题：经典论文被日期排序挤出候选、证据提取输出额度不足、模型抄写引文时改变原文。最终版本默认相关性排序、增加提取预算并限制截断重试、采用程序编号原文和模型选择编号的证据提取方式。此前失败运行保留在本地，不计作通过。

## 复跑

安装包可分别安装到 Web 或官方 headless profile。为所用 profile 配置一个可用模型，在可写工作区中运行：

```sh
dsh plugin --profile headless add /absolute/path/dsh-paper-insight-0.1.0.tgz
dsh headless --json "检索 ReAct: Synergizing Reasoning and Acting in Language Models，按十项要求完整分析并保存到本地。完成后检查报告并返回路径；工具失败则停止，不要自行拼造报告。" > trace.jsonl
node /absolute/path/dsh-paper-read/scripts/verify-acceptance.js trace.jsonl .paper-insight/<key>/<run>
```

`verify-acceptance.js` 验证真实会话轨迹中的检索、分析和最终回答，以及对应报告、证据与文件摘要。发布的 `acceptance-summary.json` 只包含本次结果统计和 SHA-256，不包含凭据、企业模型地址或完整私有会话。

网络源、模型、配额与站点解析可能变化，一次通过不等于保证所有未来论文和模型都成功。获取不到全文、来源限流、推理或结构失败时，插件会报告缺口或保留失败状态。`extracted-text` 仅代表抽取文本被分析，不等于读懂原 PDF 所有图片和公式。
