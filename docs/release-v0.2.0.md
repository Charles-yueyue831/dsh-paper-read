# v0.2.0 — 从论文研究到产品验证

升级为可恢复、分模块执行的研究工作流，并加入 DeepSeek Harness 原生“论文研究”侧边栏。包名保持 `dsh-paper-insight`。

- 23 个工具：独立分析模块、材料归档、续跑、全文历史、报告导出、版本/多论文比较、主题订阅、增量发现和本地机会聚合。
- 十模块结构化详情：技术三层解释、第一性原理、研究脉络、沙箱适配、产品能力、新产品、体验、迁移、教学和 PoC。
- 多源筛选与 Crossref、公开网页/PDF导入；元数据合并、引用时间线和 Mermaid 关系图。
- 不覆盖旧结果；阶段检查点、用量与耗时、局部重做、失败恢复和部分来源错误说明。
- 原生侧边栏复用会话工作区/模型，支持进度、取消和历史报告；本地 HTTP 边界校验。

验证：50 项自动测试通过；官方 Cordis/ToolRuntime 宿主集成通过；本地真实 Harness 完成 ReAct 十模块分析、续跑、版本比较、本地 PDF 单模块分析和浏览器工作台操作。

安装：`dsh plugin --profile web add dsh-paper-insight@0.2.0`，已有任务结束后重启 Harness 并刷新页面，点击“论文研究”。

参阅 README、API Schema、真实报告示例及验收记录。来源限流、引用索引缺口、PDF抽样、事实校验边界均在验收文档中明示；没有将未验证功能标为通过。
