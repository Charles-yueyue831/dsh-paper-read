# v0.2.7 — 阅读工作台

参考 [JoanYu/dsh-paper-reader](https://github.com/JoanYu/dsh-paper-reader) 的阅读布局，重新组织论文研究界面：

- 紧凑顶栏、左侧论文列表、右侧研究与报告阅读区；列表可筛选当前已加载记录。
- 点击已完成记录直接打开报告，未完成记录打开历史详情；完整历史查询、分页、编辑、删除与恢复仍在“研究历史”。
- 米白与蓝灰配色、适合长文的正文排版，支持浅色、深色、跟随系统并记住选择。
- 阅读章节随滚动高亮，目录跳转避开固定导航；保留证据定位、Mermaid 图表、Markdown 和产品草稿导出。
- 任务状态可收起，运行及错误状态自动显示；窄布局减少分栏。

验证：96 项自动化测试通过；真实 Cordis/工具/LLM 路由集成验证通过（28 工具、6 次模拟模型调用、10 个分析模块）；Harness 浏览器验证了已存模拟报告加载、图表渲染、目录跳转、主题切换和较窄布局无横向溢出。

本次为 UI 更新，未重新运行付费模型论文分析；界面测试所用报告明确标注为模拟数据。新增功能不包含参考项目的 PDF 翻译、配图编辑或页内问答。
