## 研究历史管理与失败恢复

- 支持研究历史新建、查询、详情、名称和备注编辑、删除及恢复；支持全文搜索、状态筛选和分页。
- 输入论文标题会先检索并匹配真实论文，修复 HarnessNet 标题被当作 ID 的错误。无法确认时展示候选，避免分析错误论文。
- 拦截误粘贴的旧错误提示，避免无效失败记录反复新增。
- 兼容已有标题失败记录、Pending paper 和保留正文的旧归档；材料缺失时提示补充论文信息。
- 按钮改为“继续完成分析”“重新分析选中内容”，添加解释；错误与任务状态使用易懂的中文。
- 编辑有修改记录和冲突检测；删除可恢复，原文及报告保持不变。

### 安装

```bash
dsh plugin --profile web add dsh-paper-insight@0.2.2
```

完成当前任务后重启 Harness、刷新浏览器，在侧边栏打开“论文研究”。
