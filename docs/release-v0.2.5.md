# v0.2.5 · 从发现论文到产品行动的四视图工作台

将原来混排的长页面拆成发现论文、创建研究、研究报告、研究历史。选择检索结果只预填论文；开始前明确研究模块、调用预算及前置条件，任务结束不强制切走当前配置。

- 新增快速阅读、深度研究、产品研究与自定义配置，前后端预设一致。
- 真实任务进度、调用用量、取消反馈；未完成研究保留恢复入口，预算暂停可调整累计预算继续。
- 报告概览显示实际材料覆盖、风险与未知用量。证据抽屉显示原文定位、自动复核、适用条件和独立人工意见。
- 产品机会按用户问题、技术能力到功能映射和 PoC 展开；PRD/PoC 导出包含记录与版本标识。
- 历史操作收拢为主操作与更多操作，详情抽屉、2–5 篇比较及软删除恢复。
- 按工作台容器宽度适配，标签页支持方向键，抽屉支持 Escape 和焦点返回。

本版本同时包含尚未发布的 0.2.4 后端：章节覆盖、累计调用预算、保守证据审查、独立人工注释与结构化产品草稿。保持现有 28 个工具兼容，不修改 Harness 核心。

验证结果见 acceptance-v0.2.5.md。当前发布候选尚未通过真实付费模型端到端验收：宿主路由返回 QUOTA / HTTP 402。不得将模拟流程通过表述为真实模型成功。
