- 自动化测试 84 项：调用预留、并发预算、失败计数、未知用量、继续累计预算、章节选择、补充阅读复用、原版本保留、保守复核、复核阶段预算恢复、人工意见并发修订、完整机会卡片、确定性草稿导出和既有回归。
- 前端构建成功。真实 Cordis/ToolRuntime/LlmRuntime 注册与卸载 28 个工具、十模块归档、只读限制和参数验证通过；此项明确使用模拟模型。
- 在隔离的 Harness Web profile 中，浏览器确认“论文研究”入口、研究模式、调用预算和历史操作正常显示。
- 浏览器输入公开 ReAct URL 后成功获取论文材料并保存检查点。真实模型 DeepSeek-V4.1-Flash 的请求返回 QUOTA / HTTP 402，未生成分析报告。继续操作复用了已存材料并保存独立失败版本。

- 本地 tgz 在独立临时目录安装成功；包内不含私有验收数据、日志、凭据或 node_modules。

## 能力限制

本机已核验 Harness 的 prepareCall/stream 支持输出上限和用量事件，但没有统一的调用前输入 Token 计数。总 Token 硬限制配置会在调用前明确拒绝。调用次数预算可用；内部可信计数适配器路径仅通过模拟测试，不声称宿主已支持。

章节识别基于标题和已抽取文本，不包括 OCR；未知章节、PDF 提取错误和缺失图表不会算作理解准确率。自动证据复核不是独立实验验证，人工意见单独版本化，不能改变原模型事实类型。
